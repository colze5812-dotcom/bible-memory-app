## 본문 검수 (2026-11-21)
547구절 전부를 대한성서공회 개역개정 원문과 `암송구절 전체(2020) A6-1.pdf`(네비 대구지구 책자)에 대조했다.
- 본문이 틀린 카드 73개 고침(대부분 개역한글 투: 너희를→여러분을, 나그네와 행인→거류민과 나그네 등). 181·183에서는 고전 12:4-6 · 렘 32:17 · 렘 23:24 · 대상 29:11-13 · 시 86:15 · 고전 3:7,8 · 사 55:10,11 · 마 24:35 · 히 4:2 · 약 2:17.
- 절 범위가 책자와 달라 바꾼 카드 7개(골 4:4-6, 골 1:29, 약 3:13,17, 딤전 4:13,15, 약 1:6,8, 마 6:30,33, 엡 6:13,16).
- **Satisfaction in God 48구절(s13)과 우리들의 핵심 가치 32구절(s6)은 구절 목록 자체가 책자와 전혀 달라서** 책자 그대로 다시 만들었다. 이전 목록은 책자에 없는 임의 구절이었다.
- 책자 본문은 전부 개역개정과 같았다(책자가 일부러 줄인 구절 없음). 검수 스크립트는 `신앙\3_암송\_본문검수\`.
- 훈련관앱 `bible-data.js`는 같은 데이터라 함께 고쳤다. 캐시 `bible-cards-v12`.
- Vision 2028 "터(기초)를 다시 세움"의 **사 59:12는 사 58:12로 바꿨다** (Vision 2028 PDF에는 59:12로 인쇄돼 있지만 주제상 58:12가 맞다고 찬영이 확인, 2026-11-21). 캐시 `bible-cards-v13`.

## 기능
- 성경 구절 암송 카드 (앞·뒤 뒤집기)
- 성경공부 문답 (과별 문제 목록)
- 글자 크기 조절
- 퀴즈 게임 모드
- PWA (홈화면 추가 가능)

## 훈련관 모드 (2026-10-25, 지금은 안 씀)
훈련관앱(`신앙_모임행사\훈련관앱`)은 같은 날 저녁에 이 앱의 데이터만 `bible-data.js`로 가져가 자체 탭(암송·공부·게임)으로 다시 만들었다. iframe은 안 쓴다.
아래 모드는 코드에 남아 있지만 호출하는 곳이 없다.
주소에 `?board=<보드id>&me=<멤버id>&name=<이름>`이 붙어 있으면 동기화 코드 대신
`boards/<보드id>/bible/<멤버id>` 아래에 답변·메모를 저장하고 외운 구절도 같이 올린다. 상단에 `🏠 이름`이 보이면 그 모드다.
파라미터가 없으면 예전처럼 동기화 코드 방식으로 동작한다. 캐시 `bible-cards-v12`(2026-11-21 본문 검수 때 올림).
