# 암송카드 앱

네비게이토 성경공부(SCL) 자료를 기반으로 한 암송·성경공부 PWA 앱입니다.

## 수록 성경공부
| 번호 | 제목 | 태그 |
|------|------|------|
| BS1 | 제자의 길 | — |
| BS2 | 예수 그리스도와 나 | — |
| BS3 | 믿음의 기초 | SCL5 |
| BS4 | 봉사에의 성장 | SCL6 |
| BS5 | Again! Rebuild 확신 | — |
| BS6 | 그리스도와의 교제 | SCL2 |
| BS7 | 그리스도와의 동행 | SCL3 | (2026-10 추가. 1과 1~12번·2과 8~23번·3과 전체. 4과와 나머지 쪽은 스캔이 없어 미수록)

## 기능
- 성경 구절 암송 카드 (앞·뒤 뒤집기)
- 성경공부 문답 (과별 문제 목록)
- 글자 크기 조절
- 퀴즈 게임 모드
- PWA (홈화면 추가 가능)

## 훈련관 모드 (2026-10-25)
훈련관앱(`신앙_모임행사\훈련관앱`)의 암송 탭이 이 앱을 iframe으로 띄운다.
주소에 `?board=<보드id>&me=<멤버id>&name=<이름>`이 붙어 있으면 동기화 코드 대신
`boards/<보드id>/bible/<멤버id>` 아래에 답변·메모를 저장하고 외운 구절도 같이 올린다. 상단에 `🏠 이름`이 보이면 그 모드다.
파라미터가 없으면 예전처럼 동기화 코드 방식으로 동작한다. 캐시 `bible-cards-v11`.

## 파일 구성
```
index.html     — 앱 전체 (데이터·로직·CSS 일체형 단일 파일)
sw.js          — 서비스 워커 (오프라인 캐시)
manifest.json  — PWA 매니페스트
icon.svg       — 앱 아이콘 (벡터)
icon.png       — 앱 아이콘 (래스터, 512×512)
```
